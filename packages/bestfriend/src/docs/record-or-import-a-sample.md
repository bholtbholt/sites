Every sample comes into Best Friend the same way: pick a source, edit it, upload it. Nothing reaches
the EP until you have had the chance to crop and process it.

## Import a file

1. On **Pads** or **Samples**, tap **+** in the toolbar.
2. Tap **Choose file…**, **Choose from Photos…**, or **Record audio…**.
3. Edit the sample and upload it. See
   [crop, normalize, repitch, and add effects](/docs/sample-editor-and-effects).

**Choose from Photos…** imports the audio from a video — a phone recording of a rehearsal, a clip you
saved, anything with a soundtrack.

On iPad and Mac, you can also **drop audio files** anywhere on Best Friend.

## Record a sample

1. Tap **Record audio…**.
2. Choose an input, and tap **Record**.
3. Pause and resume as often as you like, then tap **Stop**.
4. Play the take back, and tap **Use take** to open it in the sample editor.

The input you pick is remembered. To change the default, see [App Settings](/docs/app-settings).

## Import several files at once

File imports take a bulk selection by default. Select one or more files, then edit each in turn.
You can skip and discard any file in the batch and carry on to the next.

On iOS, the file picker cannot remember where you were for a bulk selection. To open in the same
folder every time, set the default import path in [App Settings](/docs/app-settings).

## Make a multi-sample

On the EP-40 and EP-1320, turn on **Convert to multi-sample** before choosing files or recording.
See [build a multi-sample](/docs/build-multi-samples).
