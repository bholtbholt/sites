Multi-samples let several samples live inside one playable instrument. Best Friend builds and
edits them on the **EP-1320 Medieval** and the **EP-40 Riddim**.

## Build one

1. Choose the samples you want to layer.
2. Set the **length** of the multi-sample.
3. **Crop and loop** each layer individually.
4. **Preview** the result.
5. Save the whole thing as a single waveform.

## Edit one later

A multi-sample built in Best Friend stays editable. Change one layer — re-crop it, re-loop it,
swap it — without rebuilding everything around it.

A multi-sample does not support stem-splitting.

## Device support

Multi-sample building is available on the **EP-1320 Medieval** and the **EP-40 Riddim**.

The **EP-133 K.O. II** does not support multi-samples. Everything else in Best Friend —
the pad editor, whole-bank view, Scenes, bouncing, stem splitting, and the Library — works on
the EP-133 exactly as it does on the others.
