Like I said, I love the <a href="https://teenage.engineering/products/ep-133" target="_blank">Teenage Engineering EP-133 Sampler</a> so I spent several weeks building a native iOS companion app. It connects over USB-C and functions as an extended display and feature-augmentation tool.

Beyond _finally_ being able to see and trim the waveform (with device control), I've added several file management and workflow features. You can bulk upload, move, and delete samples; create _Bank Snapshots_ to quickly load up a collection of pads at once; save storage space with my port of <a href="https://bholtbholt.github.io/repitch/" target="_blank">Repitch</a>; and reverse playback and effects to your samples. Lots more to come!
